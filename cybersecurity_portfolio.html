Мої проєкти

1. Network Traffic Analyzer

Скрипт на Python для перехоплення та базового аналізу підозрілих пакетів у локальній мережі.

2. Захист бази даних MS SQL

Розробка схеми захисту БД: обмеження прав користувачів за ролями (RBAC), шифрування чутливих даних.

3. Розробка способу вводу тексту для незрячих з використанням стандартної клавіатури

На С++ завдяки блоку NumPad розробив програму для вводу тексту на мові брайля для навчання дітей з вадами зору. Зараз програма використовується у "Криворізькому Ліцеї №1 для дітей з обмеженими можливостями"
